Spec-driven engineering discipline for AI agents.

TrueNorth-MCP is a protocol-first Model Context Protocol runtime. It delivers engineering discipline through typed tools and live resources, not a large instruction file dumped into a context window. Protocol-first, token-lean, and model-agnostic.

Install and connect Read the manual

Install

Install the npm wrapper. It resolves the platform binary and runs the server over stdio.

npm install truenorth-mcp

Then connect it as an MCP server in your client. The install and connect guide has the per-client steps.

What it does

  • Active tools, not markdown blobs

    Tools advance a lifecycle phase, record a task, and run a quality gate in a sandbox. The server observes the exit code, so a gate cannot be faked.

  • Live resources

    The project cockpit is served as truenorth:// resources that reflect the current on-disk state, with an update notification when a file changes.

  • Model and harness agnostic

    Skills render at a full, reasoning, or lean tier, so the same discipline drops into a hosted model or a local weight, across Kiro, Cursor, Claude Code, Zed, and Neovim.

  • Two-layer workspace

    The runtime writes only under .agent/, behind a single write guard. The human-authored specs/ layer stays read-only to the runtime.

A taste of the loop

An agent connects over stdio, reads the cockpit, and drives the lifecycle from Discover to Integrate. A gate passes only on a real exit 0. 

read  truenorth://state          # the active phase and handoff
call  truenorth_record_task      # register a task with a verify command
call  truenorth_verify_gate      # run the verify command in a sandbox
call  truenorth_advance_phase    # move the lifecycle forward

The lifecycle guide walks a full run, and troubleshooting covers repo-root resolution and a broken layout.
