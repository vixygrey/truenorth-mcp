# v1.2.1

## Highlights

- Scopes Red-Green-Refactor state by task group, so new issue work does not inherit a previous group’s cycle.
- Hardens deterministic methodology evaluations by restricting process launchers, environment overrides, and disposable-workspace paths.
- Validates Jev opt-in activation before the guardrail is advertised. The endpoint must use HTTPS
  and must not contain embedded credentials, query data, or a fragment.
- Builds and tests the Jev HTTP feature in CI and includes it in native release artifacts.
