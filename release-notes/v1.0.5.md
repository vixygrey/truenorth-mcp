# v1.0.5

## Highlights

- Fixes a case-insensitive filesystem alias (for example `Specs/evil.md`) that let a custom
  package bundle bypass the `specs/` write prohibition on a case-insensitive filesystem such as
  the default macOS volume.
- Fixes unvalidated persisted transaction-journal paths in workspace upgrade: `resume` and
  `rollback` now revalidate every operation path, and constrain its `staged`/`backup`
  references to the transaction's own generated shape, so a corrupted or hand-edited journal
  cannot bypass the `specs/` write prohibition or read or delete a file outside the repository.
- Documents the narrow, audited repository-seed write authority used by `init`, fresh scaffold,
  and managed upgrade (ADR-0019), distinct from the guarded `.agent/` machine-state write path.
- Records a prospective traceability evidence cutover at v1.0.4 (ADR-0020): work predating
  versioned operation receipts is dispositioned out of scope for the traceability gate, with its
  already-recovered issue, pull-request, commit, and CI evidence preserved.
- Wires a reproducible, measured coverage command into CI and local preflight.

## Tooling security

- Pins the repository-only MCP Inspector at 2.9.0 and its MCP SDK packages at 2.2.0.
  These pins resolve GHSA-6qxp-vccf-f47h in the development dependency tree.
- Locks the transitive `source-map-js` development dependency at 1.2.2.
  This lock resolves GHSA-68fv-2mgg-jv7q.
- Certifies MCP Inspector 2.9.0 against the packed 1.0.5 wrapper and a built native binary.
  The wrapper keeps its Node.js 18 minimum.

## Migration

No migration required. The published v1.0.4 package only ever declared `skills/**` paths in its
bundle manifest, so the two fixes in this release are defense-in-depth: no operator using the
published package was exposed to either bypass through normal use.
