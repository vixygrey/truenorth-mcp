# v1.1.0

## Highlights

- Adds the canonical `senior-developer` skill to the core catalog and distributed skill bundle.
- Delivers the complete Senior Developer baseline in MCP initialization instructions by default. Delivery does not require a target-local skill copy.
- Adds the default-enabled `features.senior_developer` setting. An authorized repository opt-out disables automatic delivery on the next connection. Catalog and explicit retrieval access remain available.
- Preserves the baseline's load-bearing principles in full, reasoning, and lean tiers. Instruction delivery does not enforce model judgment.

## Migration

Fresh initialization installs the new core skill automatically. Managed upgrades from v1.0.5 add it through existing ownership and collision rules. User-owned changes remain preserved.

Missing configuration defaults to enabled. To disable repository-wide delivery, explicitly authorize adding `features.senior_developer: false` to `.agent/config/rules.yml`. Reconnect the MCP client. Set the field to `true` and reconnect to enable delivery again. Conversation-only opt-outs do not modify repository files.
