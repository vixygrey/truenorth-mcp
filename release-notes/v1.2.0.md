# v1.2.0

## Highlights

- Adds YAML-backed contracts to every bundled skill. Contracts declare their scope, a concise description, side effects, risks, and handoffs so catalog and workflow tooling can inspect the skills they deliver.
- Validates required skill contracts during repository quality checks and exposes the contract data through the catalog and skill graph.
- Adds guarded Git change-boundary enforcement and clearer writer-lease remediation for parallel worktree use.
- Returns bounded, actionable diagnostics when a verification gate fails.
- Expands the GitHub Pages overview with lifecycle, runtime, workspace, capability, installation, and compatibility guidance.

## Migration

No migration required. Managed upgrades distribute the bundled skill contracts through the existing ownership and collision rules. Custom skills remain opt-in and are not rewritten by the upgrade process.
