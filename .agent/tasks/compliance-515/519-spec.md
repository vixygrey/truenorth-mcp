   - Expected: Status and timestamps match observed execution; planned checks and local RED evidence are not invented as historical facts.
   - Record: Inspect the actual status/evidence through the runtime resources and retained receipts.
   - Scenario: SC-519-P1-01

2. Build report rows once per entry, link recoverable evidence, and record real gaps and legitimate owner/rationale dispositions.
   - Expected: No duplicate or omitted entry; missing receipts and timestamps stay missing; no blanket exclusion to force PASS.
   - Record: Retain a complete entry-to-row inventory and source URLs or explicit unavailable-evidence notes.
   - Scenario: SC-519-P1-02

3. Run trace-requirement gate against the exact report generated by report mode; never mutate the real report for negative cases.
   - Expected: Only supported current complete passing evidence can pass; failure and missing evidence cannot become an automatic waiver.
   - Record: Retain report identity, evaluated head, verdict, and observed negative-case decisions.
   - Scenario: SC-519-P1-03
